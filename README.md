# MedChance 🩺

An unofficial interview eligibility estimator for Canadian medical schools.

Enter your cGPA, MCAT scores, and CASPer quartile to see how your profile stacks up against each school's published screening criteria.

## Disclaimer

This tool is an unofficial estimator based on publicly available information and community-reported trends. Admissions processes change over time and involve factors beyond GPA, MCAT, and CASPer. Results should be interpreted as estimates only and not as official admissions advice or predictions.
